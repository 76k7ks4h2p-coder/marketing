# 生まれ星占い(四柱推命・簡易版)

生年月日・出生地・出生時刻を入力すると、四柱推命ベースの性格・運気を占う Web サービスです。
OwnerBase(このリポジトリの物件管理サービス)とは完全に独立した、別アプリです。

## 使い方

```bash
cd fortune-telling
pnpm install
pnpm dev
```

`http://localhost:3000` を開いてください。

## 占いの仕組み

生年月日・出生時刻から「年柱・月柱・日柱・時柱」の干支(かんし)を計算し、
生まれた日の干(日主)をもとに性格や運気のヒントを表示します。

本格的な四柱推命が使う「節入り(二十四節気)の正確な日時」や「出生地の経度による真太陽時補正」は
省略した簡易計算です(`src/lib/fourPillars.ts` 参照)。出生地は計算そのものには使わず、
ラッキー方位・アイテムを決める材料として使っています。エンタメ用途の占いとしてお楽しみください。

## コマンド

- `pnpm dev` — 開発サーバー起動
- `pnpm build` — 本番ビルド
- `pnpm test` — 計算ロジックのテスト実行
- `pnpm lint` / `pnpm typecheck` — コード検証
